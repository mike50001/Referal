# 💱 Telegram-бот обмена валюты

Бот принимает заявки на обмен валюты от клиентов, пересылает их в чат менеджеров
и позволяет менеджеру ответить клиенту прямо из этого чата.

## Возможности

- 🤖 Пошаговый сбор заявки: что отдаёте → что получаете → сумма → контакт.
- ✅ Подтверждение заявки клиентом перед отправкой.
- 📨 Заявка автоматически уходит в чат админа/менеджеров.
- ↩️ Менеджер отвечает клиенту, просто отвечая (reply) на сообщение с заявкой —
  бот пересылает ответ клиенту от своего имени.
- 💾 Без базы данных: маршрутизация ответов работает даже после перезапуска
  (ID клиента зашит в текст заявки).

## Как это работает

1. Клиент нажимает **«Оставить заявку на обмен»** и проходит 4 шага.
2. Готовая заявка приходит в `ADMIN_CHAT_ID` (личка или группа менеджеров).
3. Менеджер делает **reply** на сообщение с заявкой и пишет текст —
   клиент получает ответ от бота.

## Установка

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Настройки
cp .env.example .env
# отредактируйте .env: впишите BOT_TOKEN и ADMIN_CHAT_ID
```

### Где взять значения

- **BOT_TOKEN** — создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
- **ADMIN_CHAT_ID** — чат, куда падают заявки:
  - Личка: напишите [@userinfobot](https://t.me/userinfobot), он покажет ваш ID.
  - Группа: добавьте бота в группу, дайте права писать — ID группы (отрицательное
    число) появится в логах бота при первом сообщении, либо используйте
    [@getmyid_bot](https://t.me/getmyid_bot).
- **ADMIN_IDS** *(необязательно)* — если `ADMIN_CHAT_ID` это группа с посторонними,
  укажите ID менеджеров через запятую, чтобы отвечать могли только они.

## Запуск

```bash
python main.py
```

## Команды бота

| Команда     | Описание                        |
|-------------|---------------------------------|
| `/start`    | Запустить бота                  |
| `/exchange` | Оставить заявку на обмен        |
| `/cancel`   | Отменить текущую заявку         |

## Структура проекта

```
main.py                  # точка входа, запуск polling
requirements.txt
.env.example
bot/
├── config.py            # загрузка настроек из .env
├── states.py            # состояния FSM (шаги заявки)
├── keyboards.py         # клавиатуры и список валют
└── handlers/
    ├── client.py        # диалог с клиентом и отправка заявки
    └── admin.py         # ответы клиентам через reply
```

## Настройка списка валют

Отредактируйте `CURRENCIES` в `bot/keyboards.py`. Клиент в любом случае может
ввести свою валюту вручную кнопкой «Другая валюта».
