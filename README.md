# Торговый бот для фьючерсов Binance (EMA/RSI)

Автоматический торговый бот для **USDT-M фьючерсов Binance** на Python.
Стратегия — пересечение скользящих средних (EMA) с фильтром по RSI.
Поддерживает **testnet** (бумажные деньги), режим **DRY_RUN** (только сигналы,
без ордеров) и встроенный **бэктест** на исторических данных.

> ⚠️ **Дисклеймер.** Торговля фьючерсами с плечом сопряжена с высоким риском
> и может привести к потере всех средств. Этот код предоставлен в
> образовательных целях. Всегда сначала тестируйте на testnet. Автор и код
> не несут ответственности за ваши убытки.

## Возможности

- Подключение к Binance USDT-M Futures (testnet и mainnet).
- **Две стратегии** на выбор (`STRATEGY`): `ema_rsi` (пересечение EMA + фильтр
  RSI) и `fast_rsi` (Fast RSI 2.0 — RSI + EMA размера тела свечи).
- Решения по **закрытым** свечам.
- Риск-менеджмент: размер позиции от % депозита, стоп-лосс и тейк-профит.
- **ATR-стоп** (`USE_ATR_STOP`) — динамические SL/TP от волатильности.
- **Трендовый фильтр старшего ТФ** (`TREND_FILTER`) — не входить против тренда.
- **Защита от просадки** (`MAX_DRAWDOWN_PCT`) — стоп новых сделок при просадке.
- **Трейлинг-стоп** (`TRAILING_STOP`) — прибыль растёт, стоп ползёт за ценой.
- **Оптимизатор параметров** (`optimize.py`) — walk-forward перебор настроек.
- Автоматическая установка плеча и типа маржи (ISOLATED/CROSSED).
- Защитные ордера SL/TP (`STOP_MARKET` / `TAKE_PROFIT_MARKET`, `closePosition`).
- Округление объёма/цены под фильтры биржи (LOT_SIZE, PRICE_FILTER, NOTIONAL).
- Режим `DRY_RUN` и офлайн-бэктест. Корректная остановка по Ctrl+C.
- База знаний по трейдингу в `docs/trading-notes.md`.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Скопируйте пример конфига и заполните ключи:

   ```bash
   cp .env.example .env
   ```

2. Получите API-ключи:
   - **Testnet** (рекомендуется для старта): https://testnet.binancefuture.com/
     → зарегистрируйтесь → раздел **API Key**.
   - **Mainnet** (реальные деньги): Binance → API Management. Для ключа
     включите **Enable Futures**, ограничьте доступ по IP, **не** включайте вывод средств.

3. Пропишите ключи в `.env` и оставьте `USE_TESTNET=true` для проверки.

Основные параметры (`.env`):

| Переменная | Описание |
|-----------|----------|
| `USE_TESTNET`       | `true` — тестовая сеть, `false` — реальные деньги |
| `SYMBOL`            | Торговая пара, напр. `BTCUSDT` |
| `INTERVAL`          | Таймфрейм: `1m`,`5m`,`15m`,`1h`,`4h`… |
| `LEVERAGE`          | Плечо |
| `RISK_PER_TRADE`    | Доля депозита на сделку (`0.01` = 1%) |
| `STOP_LOSS_PCT`     | Стоп-лосс, доля от цены (`0.015` = 1.5%) |
| `TAKE_PROFIT_PCT`   | Тейк-профит, доля от цены |
| `MAX_POSITION_USDT` | Максимальный номинал позиции |
| `EMA_FAST`/`EMA_SLOW` | Периоды EMA |
| `RSI_PERIOD` и пороги | Настройки RSI-фильтра |
| `DRY_RUN`           | `true` — только сигналы в лог, без ордеров |

## Бэктест (без ключей)

Проверьте стратегию на исторических свечах перед запуском:

```bash
python backtest.py --symbol BTCUSDT --interval 1h --limit 1000
```

Выводит число сделок, винрейт и итоговый P&L. Помогает подобрать параметры
EMA/RSI и SL/TP.

## Запуск бота

Сначала — «сухой прогон» без ордеров, чтобы посмотреть на сигналы:

```bash
# в .env выставьте DRY_RUN=true
python bot.py
```

Затем — реальная торговля на **testnet** (`USE_TESTNET=true`, `DRY_RUN=false`):

```bash
python bot.py
```

Остановка — `Ctrl+C` (бот завершит текущую итерацию и выйдет).

## Как работает стратегия

- **LONG**: `EMA_fast` пересекает `EMA_slow` снизу вверх и RSI ниже уровня
  перекупленности.
- **SHORT**: `EMA_fast` пересекает `EMA_slow` сверху вниз и RSI выше уровня
  перепроданности.
- **Выход**: обратное пересечение EMA закрывает позицию; параллельно на бирже
  стоят защитные SL и TP.

Сигналы считаются по **последней закрытой** свече — формирующаяся свеча
отбрасывается, чтобы избежать «перерисовки» сигнала.

## Рекомендации по безопасности

- Начинайте **только** с testnet и `DRY_RUN`.
- Никогда не коммитьте `.env` (он в `.gitignore`).
- Ограничьте API-ключ по IP и **не** давайте право на вывод средств.
- Тестируйте малыми суммами, следите за логами.
