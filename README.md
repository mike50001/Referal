# Свой VPN для России (VLESS + Reality)

VPN для себя и друзей (~20 человек), живущих в России, с надёжным обходом
блокировок. Работают **WhatsApp, Telegram, YouTube, Instagram** и всё остальное.

## Почему именно так

Обычные VPN (WireGuard, OpenVPN, IKEv2) в России распознаёт и режет DPI
(система блокировок РКН). Поэтому здесь используется **VLESS + Reality** —
протокол, который маскируется под обычный визит на реальный крупный сайт
(HTTPS). Для DPI это выглядит как обычный трафик на `microsoft.com`, и
отличить его практически невозможно.

## Стек

| Компонент | Что это | Зачем |
|---|---|---|
| **VPS** за границей | Сервер (Нидерланды / Германия / Финляндия) | Точка выхода в «свободный» интернет |
| **3x-ui** | Веб-панель управления | Добавлять пользователей в пару кликов |
| **Xray-core** | Движок | Реализует VLESS + Reality |
| **Hiddify** | Приложение для друзей | Одна ссылка → подключился |

## Быстрый путь

```bash
# на свежем сервере Ubuntu 22.04/24.04, под root:
bash <(curl -Ls https://raw.githubusercontent.com/mike50001/referal/claude/custom-vpn-8o0v15/scripts/install.sh)
```

Дальше — по шагам 3–4, чтобы поднять Reality и раздать доступы.

## Стоимость

- VPS: ~5–8 $/мес на всех 20 человек (можно скинуться).
- Приложения: бесплатные.
- Сам VPN: бесплатный (open-source).

## Важно про закон

Пользоваться VPN для доступа к WhatsApp, YouTube, Telegram и т.п. — это личное
использование. Не размещай сервис публично и не продавай доступ — раздавай
только знакомым.
