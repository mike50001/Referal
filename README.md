# 🌸 Бот-подруга для Telegram

Тёплый и живой чат-бот для Telegram, который общается с тобой как близкая подруга.
«Мозг» — OpenAI (ChatGPT), так что ответы получаются естественными и осмысленными,
а бот помнит, о чём вы говорили в течение разговора.

## Что умеет

- 💬 Общается живым разговорным языком, а не как сухой ассистент
- 🧠 Помнит контекст разговора (последние сообщения)
- 🙂 Имеет заданный характер — тёплый, внимательный, с интересом к тебе
- ⌨️ Показывает «печатает…», пока думает над ответом
- 🔧 Легко настраивается: имя и характер — в одном файле `personality.py`

## Что нужно для запуска

1. **Python 3.10+**
2. **Токен Telegram-бота** — бесплатно за минуту (см. ниже)
3. **Ключ OpenAI API** — https://platform.openai.com/api-keys (оплата по мере использования)

## Пошаговая настройка

### 1. Создай своего бота в Telegram

1. Открой в Telegram чат с [@BotFather](https://t.me/BotFather)
2. Отправь команду `/newbot`
3. Придумай имя и username бота (username должен заканчиваться на `bot`)
4. BotFather пришлёт тебе **токен** вида `123456789:AА...` — скопируй его

### 2. Получи ключ OpenAI

1. Зайди на https://platform.openai.com/api-keys
2. Нажми **Create new secret key**, скопируй ключ (он показывается один раз)
3. Пополни баланс на несколько долларов в разделе Billing — этого хватит надолго,
   модель `gpt-4o-mini` очень дешёвая

### 3. Установи проект

```bash
# Клонируй репозиторий и зайди в папку
git clone <адрес-репозитория>
cd Referal

# (рекомендуется) создай виртуальное окружение
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# Установи зависимости
pip install -r requirements.txt
```

### 4. Впиши свои ключи

Скопируй файл-образец и заполни его своими значениями:

```bash
cp .env.example .env
```

Открой `.env` и вставь токен бота и ключ OpenAI:

```
TELEGRAM_BOT_TOKEN=123456789:твой_токен_от_BotFather
OPENAI_API_KEY=sk-твой_ключ_openai
```

> ⚠️ Файл `.env` содержит секреты и **не** попадёт в git (он в `.gitignore`).

### 5. Запусти бота

```bash
python bot.py
```

Теперь открой своего бота в Telegram, нажми **Start** — и общайся! 💬

## Команды в чате

| Команда  | Что делает                          |
|----------|-------------------------------------|
| `/start` | Начать заново и познакомиться        |
| `/reset` | Забыть текущий разговор              |
| `/help`  | Показать подсказку                   |

## Как поменять характер и имя

Всё в файле [`personality.py`](personality.py):

- `BOT_NAME` — имя подруги
- `SYSTEM_PROMPT` — характер и стиль общения (можешь переписать под себя)
- `GREETING` — приветствие при `/start`

После изменений просто перезапусти `python bot.py`.

## Настройки (необязательно)

В файле `.env` можно задать:

- `OPENAI_MODEL` — модель OpenAI (по умолчанию `gpt-4o-mini`)
- `HISTORY_LIMIT` — сколько последних сообщений помнить (по умолчанию `20`)

## Важно

- Память разговора хранится в оперативной памяти: при перезапуске бота
  история очищается. Для постоянной памяти можно подключить базу данных.
- Не выкладывай свои токены и ключи в открытый доступ.
