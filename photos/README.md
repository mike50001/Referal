# Папка с фотографиями бота

Сюда клади картинки, которые бот будет отправлять по команде `/photo`
или когда его попросят прислать фото.

## Правила

- Поддерживаются форматы: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`
- Бот выбирает **случайную** картинку из этой папки
- Если папка пустая — бот в своём стиле откажется присылать фото

## Важно про содержимое

Клади сюда только те изображения, на которые у тебя **есть права**:
свои картинки, арты, стоковые фото с подходящей лицензией и т. п.

Не используй чужие личные фотографии и фотографии реальных людей без их
согласия — это нарушает их права и правила Telegram. Не размещай здесь
материалы сексуального характера.
