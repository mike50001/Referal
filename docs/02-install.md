# Шаг 2. Установить панель 3x-ui

Всё делается на сервере, под `root`. Подключись по SSH (см. шаг 1).

## Вариант А. Автоматический скрипт (рекомендуется)

Скрипт из этого репозитория обновит систему, включит ускорение сети (BBR),
настроит фаервол и поставит 3x-ui:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mike50001/referal/claude/custom-vpn-8o0v15/scripts/install.sh)
```

## Вариант Б. Вручную

```bash
# 1. Обновить систему
apt update && apt upgrade -y

# 2. Включить BBR (ускоряет соединение)
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p

# 3. Поставить 3x-ui (поддерживаемый форк MHSanaei)
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

Во время установки 3x-ui спросит логин, пароль и порт панели — **задай свои**,
не оставляй стандартные. Запиши их.

## Вход в панель

После установки в консоли будет строка вида:

```
Access URL: http://203.0.113.10:2053/xxxxxxxx
```

Открой этот адрес в браузере и войди под своим логином/паролем.

> Если панель не открывается — скорее всего фаервол блокирует порт. Разреши его:
> `ufw allow 2053` (подставь свой порт панели).

## Безопасность панели (обязательно)

Панель управляет всем VPN — её нельзя оставлять открытой для всех.

В настройках 3x-ui (Panel Settings) проверь / задай:

- **Сложный пароль** и нестандартный **логин**.
- **Случайный путь URL** (`Panel URL Path`), например `/a8Kd2xPq` — чтобы адрес
  панели нельзя было угадать.
- По желанию — включить **TLS для панели** (own domain + сертификат), но для старта
  не обязательно.

Порты, которые должны быть открыты в фаерволе:

| Порт | Зачем |
|---|---|
| 22 | SSH (управление сервером) |
| 443 | сам VPN (VLESS Reality) |
| порт панели (напр. 2053) | вход в 3x-ui |

Готово — переходи к [настройке Reality](03-reality.md).
