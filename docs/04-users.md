# Шаг 4. Добавить пользователей (тебя + 19 друзей)

Каждому пользователю — **свой отдельный доступ** (свой UUID). Это важно:

- можно отключить одного, не трогая остальных;
- видно, кто сколько трафика ест;
- если чей-то доступ «утёк» — удаляешь только его.

## Добавить клиента

1. В **Inbounds** найди свой `reality`-inbound → нажми **+** (Add Client) или
   значок пользователей.
2. Заполни на каждого:

| Поле | Значение |
|---|---|
| Email / Remark | имя, чтобы не путаться: `ivan`, `masha`, `me` |
| Flow | **xtls-rprx-vision** |
| ID (UUID) | оставь автосгенерированный |
| Total GB | `0` = безлимит (или лимит, напр. `100` ГБ) |
| Expiry | пусто = бессрочно (или дата) |

3. Повтори для всех 20 человек. UUID у каждого свой — не копируй один на всех.

## Как раздать доступ

У каждого клиента есть кнопки:

- **QR-код** — друг сканирует камерой в приложении.
- **Ссылка** (`vless://...`) — отправляешь в мессенджер, друг вставляет в приложение.

### Рекомендуется: включить подписку (Subscription)

Подписка удобнее ссылки: если ты поменяешь настройки сервера (например, сменишь
IP), у друга всё обновится **автоматически**, ничего пересылать не надо.

1. Panel Settings → **Subscription** → включи, задай порт (напр. `2096`) и путь.
2. Открой этот порт в фаерволе: `ufw allow 2096`.
3. У каждого клиента появится **Subscription URL** — её и отправляй другу вместо
   обычной ссылки.

## Управление потом

- **Отключить человека:** сними галочку Enable у его клиента.
- **Удалить:** удали клиента — его ссылка сразу перестанет работать.
- **Заменить доступ:** нажми обновить UUID — старая ссылка умрёт, дай новую.
- **Трафик:** в списке виден расход по каждому.

Дальше — отправь друзьям [памятку](05-clients.md) и их ссылку/подписку.
