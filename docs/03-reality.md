# Шаг 3. Настроить VLESS + Reality

Это сердце обхода блокировок. Настраивается один раз в панели 3x-ui.

## Создать inbound

1. В панели открой **Inbounds** → **Add Inbound**.
2. Заполни:

| Поле | Значение | Комментарий |
|---|---|---|
| Remark | `reality` | любое имя |
| Protocol | **VLESS** | |
| Port | **443** | маскируемся под обычный HTTPS |
| Security | **Reality** | самое важное |
| Flow (у клиента) | **xtls-rprx-vision** | выставляется при добавлении пользователя |

## Настройки Reality

В блоке Reality:

- **Dest / Target:** `www.microsoft.com:443`
- **SNI / Server Names:** `www.microsoft.com`

«Dest» — это реальный сайт, под который мы маскируемся. Требования к нему:

- поддерживает **TLS 1.3** и **HTTP/2**;
- крупный, не заблокирован в РФ, находится **за границей** (не .ru);
- желательно за CDN.

Хорошие варианты (можно взять любой):

- `www.microsoft.com`
- `www.nvidia.com`
- `dl.google.com`
- `www.cloudflare.com`
- `www.yahoo.com`

> Не используй сайты, которые могут быть заблокированы в РФ (Google-сервисы
> частично тормозят), и не бери мелкие/российские сайты. `www.microsoft.com` —
> самый безопасный дефолт.

## Ключи

3x-ui сгенерирует автоматически (кнопка **Get New Cert** / стрелочки):

- **Private Key** и **Public Key** (пара ключей Reality);
- **Short IDs** — оставь как есть или сгенерируй.

Ничего вручную считать не нужно — панель делает всё сама. Просто убедись, что
поля Private Key, Public Key и Short IDs заполнены.

## Сохранить

Нажми **Create / Add**. Inbound появится в списке. Теперь на порту 443 работает
Reality — осталось добавить людей ([шаг 4](04-users.md)).

## Проверка (для себя)

Добавь себя первым пользователем, импортируй ссылку в Hiddify/v2rayNG
([шаг 5](05-clients.md)) и открой, например, `youtube.com`. Если видео грузится —
всё работает.
