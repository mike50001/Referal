# База знаний по трейдингу

Конспект учебного курса по крипто-/фьючерсной торговле, оформленный как
справочник для развития бота. Разделы, помеченные 🤖, напрямую переносятся
в код (стратегии/фильтры/риск).

---

## 1. Базовые понятия

- **Валютная пара**: базовая / котируемая (ETH/BTC — покупаем ETH за BTC).
- **Bid** — цена покупателя, **Ask** — цена продавца, **Spread** — разница.
- **Long** — покупка в расчёте на рост; **Short** — продажа в расчёте на падение.
- **Типы ордеров**:
  - Market — исполняется сразу по рынку.
  - Limit — по указанной цене или лучше (Buy Limit ниже рынка, Sell Limit выше).
  - Stop (Buy Stop выше рынка, Sell Stop ниже) — вход/выход по пробою.
  - Stop-Limit — при достижении stop-цены выставляется лимитный ордер.
  - Stop-Loss — защитный стоп для ограничения убытка.

## 2. Стили торговли

| Стиль | Горизонт | Примечание |
|-------|----------|-----------|
| Скальпинг | секунды–минуты | Самый прибыльный, но нервный; удел роботов |
| Дейтрейдинг | 1 час – 1 день | **Рекомендован новичкам** |
| Свинг | неделя – месяц | Нужна терпеливость |
| Позиционный | месяц+ | Терпит просадки 10–15% |
| Арбитраж | — | Только для больших объёмов |

## 3. Тренд и уровни

- **Тренд**: восходящий / нисходящий / флэт (боковик).
- Поддержка строится по минимумам (в аптренде), сопротивление — по максимумам.
- **Сила уровня** зависит от: (1) длительности и числа касаний, (2) ширины зоны,
  (3) объёма сделок. От сильных уровней входить безопаснее.
- Уровни «стареют» — ~70% игроков ежегодно уходят с рынка.
- **Правило канала**: делите канал пополам — середина работает как S/R.
- **Правило хода**: движение из канала обычно равно величине канала.

## 4. Числа Фибоначчи

- Уровни коррекции: **23.6 / 38.2 / 50 / 61.8 / 78.6 / 100 %**.
- Натягивать слева-направо по ходу тренда, от пика до пика (со тенями).
- На крипте цена часто корректируется к 61.8%.
- Смотреть на старших ТФ (от 3–6 часов).

## 5. Индикаторы

Два класса:
- **Трендовые (отстающие)**: хорошо в тренде, плохо во флэте, запаздывают.
- **Осцилляторы (опережающие)**: хорошо во флэте, много ложных сигналов в тренде.

### Скользящие средние (MA) 🤖
- **SMA** — простая (долгосрок); **EMA** — экспоненциальная, чувствительнее
  (краткосрок); **WMA** — взвешенная.
- Периоды: долгосрок 80–200, среднесрок 30–75, краткосрок 5–30.
- Брать минимум две MA, старшая ≥ ×2 младшей.
- **Сигнал**: быстрая пересекает медленную снизу-вверх → покупка (усиливается,
  если обе направлены вверх); сверху-вниз → продажа.
- Порядок для аптренда: сверху лёгкая, ниже средняя, ниже тяжёлая.
  Лёгкая пересекает тяжёлую → возможен разворот тренда.

### Bollinger Bands (BB)
- Средняя = MA (период 13–24, чаще 20); границы = ±2–3 σ (стандартных отклонения).
- ~90–95% цен внутри канала. Сужение полос → готовность к импульсу.
- Выход за границу → продолжение тренда; редкий сильный вылет → возможен
  контртренд (осторожно). Движение от одной границы обычно доходит до другой.
- Использовать в трендовых системах: вход по тренду после отката к средней +
  подтверждение осциллятором (Stochastic/RSI).

### RSI 🤖
- Осциллятор скорости цены (Wilder, период 14). Шкала 0–100.
- Перекупленность >70 (или 80), перепроданность <30 (или 20).
- В сильном тренде даёт много сигналов перекуп./перепрод. в одну сторону.
- Сигнал перекуп./перепрод. = замедление, НЕ гарантированный разворот.
- Лучше как фильтр в комбинации с трендовым индикатором.

### Stochastic 🤖
- %K (быстрый) и %D (медленный), 0–100. Зоны: >80 перекуп., <20 перепрод.
- Сигналы: пересечение линий, вход/выход из зон, дивергенция.
- Лучше во флэте; фишка курса — накладывать несколько стохастиков разных
  периодов (14-3-1, 21-7-1, 33-14-1, 55-21-1) и смотреть зоны их пересечения.

### MACD 🤖
- Линия MACD = EMA(12) − EMA(26); сигнальная = EMA(9) от MACD; гистограмма =
  MACD − сигнальная.
- Сигналы: пересечение сигнальной, пересечение нулевой линии, дивергенция.
- Трендовый осциллятор — лучше на волатильном рынке с трендом. Запаздывает.

### Awesome Oscillator (AO)
- SMA(5) − SMA(34) по медианной цене (High+Low)/2. Гистограмма ±0.
- Сигналы: пересечение нуля, «блюдце», «два пика». Нельзя покупать на красном
  баре / продавать на зелёном. Создан Вильямсом для фьючерсов.

### ATR (волатильность) 🤖
- Средний истинный диапазон, период 14, ТФ от H1. «Запас хода» цены.
- Низкий ATR (после боковика) → сжатая пружина, скоро импульс.
- Резкий всплеск ATR → движение скоро выдохнется (разворот/коррекция).
- Применение: вход в тренд после боковика; фиксация прибыли на пике ATR.
- 🤖 Можно использовать для **динамических стоп-лоссов** (SL = N × ATR).

### Aroon
- Aroon Up/Down (0–100), период 14 или 25. Измеряет, сколько периодов назад
  был максимум/минимум. Up>70 & Down<30 → сильный аптренд (и наоборот).
- Пересечение линий → смена тренда/выход из флэта.

### Прочие
- **Williams %R** (период 14) — осциллятор перекуп./перепрод., как фильтр.
- **OBV** — On Balance Volume, только на дневных ТФ; подтверждение тренда,
  дивергенции.
- **Volume Oscillator** — разность EMA объёмов; пересечение нуля = рост объёма.
- **Mayer Multiple** = Цена / SMA(200). >2.4 сильная перекупленность, <1
  под средней. Инструмент для BTC.
- **Keltner Channel** — канал на базе среднего диапазона; S/R на старших ТФ.
- **Linear Regression (LRI)** — канал регрессии; торговля на разворот/пробой.
- **Heiken Ashi** — сглаженные свечи, фильтруют шум; зелёные без нижних теней =
  сильный аптренд; считать число одинаковых свечей подряд.

## 6. Дивергенция / конвергенция

- **Дивергенция** (медвежья): цена делает новый максимум, индикатор — нет.
- **Конвергенция** (бычья): цена делает новый минимум, индикатор — нет.
- Сильный сигнал разворота; работает после длинного размеренного движения,
  неэффективна после резких скачков.

## 7. Свечной анализ и VSA

**Разворотные модели**: доджи, молот/повешенный, поглощение (бычье/медвежье),
харами, три вороны / три солдата.
**Модели продолжения**: метод трёх свечей, удержание на татами.

Правила:
- Решение — только после **закрытия** свечи (чем старше ТФ, тем надёжнее).
- Молот: нижняя тень в 2–3× тела, тело вверху, подтверждение следующей свечой.
- Поглощение: работает после чёткого тренда; сильнее, когда 2-я свеча большая.

**VSA (Volume Spread Analysis)**: рынками движут крупные игроки.
- Фазы: накопление → рост/падение → распределение.
- Высокий объём при малой свече = встречное сопротивление (движение выдыхается).
- Большая свеча с большим объёмом = импульс продолжения.
- Здоровый тренд — средний объём и средний размер свечей.
- Ключ: усилие vs результат (был объём — а что цена сделала дальше?).

## 8. Графические фигуры

| Фигура | Тип | Вход | Стоп | Тейк |
|--------|-----|------|------|------|
| Двойная вершина/дно | разворот | пробой линии шеи | за экстремум | высота фигуры от шеи |
| Голова и плечи (ГиП/пГиП) | разворот | пробой линии шеи | за плечо | высота головы |
| Треугольник (сим/восх/нисх) | продолжение* | пробой границы + объём | за пробитую линию | высота треугольника |
| Флаг / вымпел | продолжение | пробой канала | вершина коррекции | высота флагштока |
| Клин | продолжение | пробой крутой линии | за минимум пробойной свечи | — |
| Прямоугольник | продолжение | пробой границы | за противоположную границу | высота фигуры |
| Пин-бар | разворот | пробой на след. свече (stop-ордер) | за хвост | 1.5–2× стопа |

\* Симметричный треугольник ~30% ложных пробоев. Пробой обязательно
подтверждать объёмом; без роста объёма — вероятен ложный пробой.

## 9. Психология

- **Три эмоции**: страх, жадность, надежда. Не спешить, не входить «всей котлетой».
- **Психологический лимит** на сумму сделки: резкое повышение депозита ломает
  систему. Наращивать депозит плавно, выводить прибыль частями.
- **90-90-90**: 90% новичков теряют 90% депозита за 90 дней.
- Обязателен самоанализ: разбор сделок, стопов, ошибок после сессии.

## 10. 🤖 Риск-менеджмент (для кода)

**Таблица восстановления после просадки** (сколько нужно заработать, чтобы отбить):

| Просадка | Нужно восстановить |
|----------|--------------------|
| 10% | 11.1% |
| 20% | 25% |
| 30% | 42.9% |
| 40% | 66.7% |
| 50% | 100% |
| 60% | 150% |
| 70% | 233% |
| 80% | 400% |
| 90% | 900% |

Правила (Money Management):
1. **Фиксированный риск на сделку**: 1–2% от депозита. Растёт депозит — растёт
   объём, падает — снижается.
2. **Risk:Reward** минимум **1:3** (цель — поймать в 3+ раза больше риска).
3. **Суммарный риск портфеля** ≤ 20–30%. Учитывать риск ВСЕХ открытых сделок,
   а не каждой по отдельности.
4. **Плечо**: новичкам избегать; если брать — не выше **×3–×5**. Выше ×5 —
   почти гарантированный слив.
5. **Максимальная просадка**: не допускать больше 20–30% от депозита.
6. Старший ТФ = меньше риска и шума (время как фильтр).

## 11. 🤖 Формализованные стратегии

### Fast RSI 2.0 (урок 13) — полностью алгоритмизуема
Индикаторы: RSI + EMA размера тела свечи.
- **EMA Body**: тело свечи = |close − open|; средний размер тела = EMA(30) от тела.
- Свечи с телом < ½ среднего игнорируются (слишком мелкие).
- Правила (`RSI Limit` — параметр, напр. 40):
  - RSI < RSI_Limit И тело > средн./4 → **открыть LONG**
  - RSI > RSI_Limit И тело > средн./2 → **закрыть LONG**
  - RSI > (100 − RSI_Limit) И тело > средн./4 → **открыть SHORT**
  - RSI < (100 − RSI_Limit) И тело > средн./2 → **закрыть SHORT**
- ТФ: 5m–1h. Стопы обязательны.

### ZZ-2 (урок 13) — реверсивная
- Работает в обе стороны. Цена выше зелёной линии → long; ниже красной → short.
  (Опирается на публичный индикатор ZigZag-подобного типа, требует уточнения
  формулы линий перед реализацией.)

### Базовая система курса (комбинация)
Трендовый фильтр (MA/BB) + осциллятор для тайминга (RSI/Stochastic/MACD/AO) +
подтверждение объёмом. Не входить против тренда. Решения по закрытым свечам.
